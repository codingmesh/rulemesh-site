# Complete client templates

Shadowrocket uses Home nodes. Other templates require your node base; use config compose locally. Injection fields are not usable proxy entries.

Standard excludes advertising; advertising variants explicitly enable it. sing-box uses its native reject action; switch variants to change blocking instead of inventing a block outbound. Supply a real named CN rule set in your own sing-box base.

Rule membership updates refresh existing resources. New references, formats, targets or group structure require configuration upgrade.
